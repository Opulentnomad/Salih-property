# تطبيق ثواني لأندرويد (Kotlin + Jetpack Compose)

نسخة أصلية (Native) من موقع ثواني: 47 بطاقة طوارئ، خطوة بخطوة وبالصوت، إيقاع الإنعاش، مؤقت العاصبة، قوائم التجهيز، أسئلة وخرافات، أرقام الطوارئ، وضع الطوارئ، وأوضاع الأعمار.

## التشغيل
1. افتح مجلد `android/` في **Android Studio** (Koala أو أحدث) ثم Run، أو من الطرفية:
   ```
   cd android
   ./gradlew :app:assembleDebug     # APK للتجربة
   ./gradlew :app:assembleRelease   # APK بحجم أصغر (موقّع بمفتاح debug للتثبيت المباشر)
   ```
   الناتج في `app/build/outputs/apk/`. يحتاج JDK 17+ وAndroid SDK 35.
2. على الجوال: فعّل «تثبيت من مصادر غير معروفة» ثم افتح ملف APK.

## تحديث البيانات
البطاقات والمصادر والقوائم والأسئلة والرسوم **تُولَّد** من ملفات الموقع (`data.js` و`illus.js`):
```
node tools/gen-kotlin.js
```
لا تعدّل ملفات `Data*.kt` يدوياً.

## للنشر في Google Play
غيّر `applicationId` في `app/build.gradle.kts` إن أردت، وأنشئ مفتاح توقيع خاصاً بك (لا يُرفع إلى المستودع) واستبدل `signingConfig` في نوع `release`، ثم ابنِ AAB: `./gradlew :app:bundleRelease`.

## ملاحظات
- لا يجمع التطبيق أي بيانات ولا يتصل بأي خادم. الإنترنت مطلوب فقط لفتح الروابط والفيديو.
- القراءة الصوتية تحتاج بيانات صوت عربي في إعدادات «تحويل النص إلى كلام» بالجهاز.
- الاتصال يفتح تطبيق الهاتف برقم الطوارئ ولا يتصل تلقائياً.
- المحتوى الطبي لم يراجعه مختص بعد.
