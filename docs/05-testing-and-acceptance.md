# استراتيجية الاختبار ومعايير القبول

## هرم الاختبار
| النوع | الأداة | الهدف |
|---|---|---|
| وحدة | Vitest/Jest | منطق التوصية، المحوّل، تحويل تواريخ هجري/ميلادي، تحليل شروط الدخول ≥ 80% تغطية |
| تكامل API | Supertest + Testcontainers | العقود (OpenAPI Contract Tests) |

## معايير القبول (Given/When/Then)
1. **شروط الدخول:** عند فتح وجهة، تُعرض خلال < 1ث: نوع الدخول، المدة، صلاحية الجواز، المستندات، التطعيم، الحجر، السفارة، تاريخ آخر تحقق، المصدر، وإخلاء المسؤولية.
2. **حداثة:** إذا `verified_at` أقدم من 30 يومًا تظهر علامة «قد تكون قديمة» ويُنبَّه المحرر.
3. **البحث والفلاتر:** إدخال «اسطنبول» أو «Istanbul» يعيد تركيا؛ الجمع بين فلاتر يعيد تقاطعها؛ لا نتائج ⇒ رسالة إرشادية.
4. **المفضلة:** الحفظ يتم فوريًا ويبقى بعد إعادة التحميل وعلى الأجهزة (بعد الدخول) ويُقرأ دون اتصال.
5. **الرحلات:** تعديل الأيام والخطة يُحفظ تلقائيًا؛ وجهة تتطلب تأشيرة تعرض تذكير إجراءات.
6. **العملات:** التحويل صحيح لأقرب منزلتين؛ عند فشل الشبكة تُعرض آخر أسعار محفوظة مع تاريخها.
7. **التنبيهات:** تغيّر شروط وجهة متابَعة يُنتج إشعارًا خلال 15 دقيقة؛ يمكن إلغاء الاشتراك.
8. **PWA:** قابلة للتثبيت؛ الصفحة الرئيسية والمفضلة وآخر وجهات شوهدت تعمل دون اتصال.
9. **RTL/لغة:** كل الشاشات سليمة في RTL؛ التبديل للإنجليزية يعكس الاتجاه دون كسر التخطيط.
10. **الوصول:** صفر مخالفات axe حرجة؛ التنقل كاملًا بلوحة المفاتيح؛ أهداف لمس ≥ 44px.
11. **الأداء:** LCP ≤ 2.5ث، CLS ≤ 0.1، INP ≤ 200ms على Moto G Power/4G.
12. **الأمان والخصوصية:** لا أسرار بالعميل؛ موافقة تتبّع؛ تصدير/حذف الحساب خلال 30 يومًا (PDPL).
13. **CMS:** المحرر ينشئ مسودة، المراجع يوافق، يُسجَّل في `audit_log`، النشر يظهر خلال دقيقة.
14. **الأفلييت:** كل رابط حجز يحمل `rel="sponsored"` وإفصاحًا ويُتتبَّع النقر.

## تعريف «تم» (DoD)
كود مُراجَع، اختبارات خضراء، لا مخالفات a11y، ترجمة عربية مراجَعة لغويًا، توثيق API محدّث، قياسات (Events) مضافة.
