# وجهة — تطبيق Android (Kotlin + Jetpack Compose)

تطبيق سفر بالعربية (RTL) والإنجليزية يقترح الوجهات حسب ذوقك، ويولّد مسار الرحلة، ويعرض صور كل وجهة **مباشرة من الإنترنت**.
التصميم مستوحى من الصور المرجعية: غلاف الرحلة وتبويباتها وفقاعات التواريخ الباستيل، ومعرض «صور الرحلة».

## الميزات في هذا الإصدار
- تهيئة بالوسوم والميزانية، وتخزين التفضيلات على الجهاز.
- «مقترحة لك»: ترتيب بتشابه جيب التمام بين وسوم المستخدم والوجهة، مع نسبة تطابق وأسباب، وتعلّم مباشر من زر القلب و«ليس لي».
- 8 وجهات (سانتوريني، ميكونوس، إسطنبول، المالديف، تبليسي، كابادوكيا، برشلونة، العُلا) × 8 أنشطة.
- منشئ المسار: يختار الأنشطة الأعلى ملاءمة، يوزّعها على الأيام، يرتّب الأوقات دون تداخل، ويسمح بالحذف وإعادة الاقتراح.
- شاشة الرحلة: المسار، اليوميات (إضافة ذكرى)، الصور، الخريطة (فتح تطبيق الخرائط)، ومشاركة الرحلة.
- شاشة «صور الرحلة»: فلاتر حسب المكان وقلب المفضلة.

## مصدر الصور
تُجلب وقت التشغيل ولا تُضمَّن في الـ APK:
- **الغلاف**: صورة المقال الرئيسية من Wikipedia REST API (`/page/summary/<الوجهة>`).
- **المعرض**: بحث في Wikimedia Commons عن صور JPEG عالية الدقة (≥ 1200px) مع استبعاد الخرائط والشعارات.
- التخزين المؤقت بـ Coil (ذاكرة 25٪ + قرص 150MB). دون اتصال يظهر تدرج لوني لكل وجهة.
- ملاحظة ترخيص: صور Commons بتراخيص حرة متنوعة (CC BY / CC BY-SA / عام). قبل النشر على المتجر أضف شاشة «حقوق الصور» تعرض المؤلف والترخيص من حقل `extmetadata` في نفس الاستدعاء.

## البناء
المتطلبات: JDK 17 وAndroid SDK 34.

```bash
cd wijha-android
./gradlew assembleDebug
# الناتج: app/build/outputs/apk/debug/app-debug.apk
```

أو شغّل سير عمل GitHub Actions **Build Android APK** (تبويب Actions ← Run workflow)، وحمّل الملف من Artifacts باسم `wijha-debug-apk`.

نسخة release تُوقَّع حالياً بمفتاح debug للتجربة. للنشر أنشئ keystore خاصاً وعدّل `signingConfig` في `app/build.gradle.kts`.

## الهيكل
```
app/src/main/java/com/wijha/app/
  Data.kt         الوجهات والأنشطة والوسوم ونماذج الحالة
  Logic.kt        التوصية، مولّد المسار، جلب الصور، التخزين المحلي
  Ui.kt           الألوان والمكوّنات المشتركة ومعرض الصور
  Screens.kt      التهيئة، الاستكشاف، التفاصيل، المنشئ، الرحلة، الصور، الحساب
  MainActivity.kt الـ ViewModel ونقطة الدخول
```
