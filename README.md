# سفرنا — دليل المسافر السعودي 🧳

تطبيق ويب تقدّمي (PWA) عربي أولًا لمسافري المملكة: شروط الدخول والتأشيرة، المفضلة، الرحلات، العملات، والتنبيهات.

## تجربة النموذج الأولي (يعمل الآن)
```bash
cd app && python3 -m http.server 8000   # ثم افتح http://localhost:8000
```
- `app/index.html` التطبيق (ترحيب، بحث وفلاتر، تفاصيل وجهة، مراجعات، مفضلة، رحلات، محوّل عملات، تنبيهات، عربي/English، داكن/فاتح، يعمل دون اتصال)
- `app/admin.html` لوحة CMS تجريبية (الرمز: `admin`) لتحرير شروط الدخول
- ⚠️ **البيانات تجريبية** ويجب التحقق منها من Timatic/المصادر الرسمية قبل الإطلاق.

## الخطوة التالية للإنتاج
استبدال `data.js` وتخزين المتصفح بـ API وقاعدة بيانات (انظر المخطط)، وربط مزوّد شروط الدخول.
